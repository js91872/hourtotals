# HourTotals

Production source for **HourTotals.com**, a fast U.S.-focused time and work-hours calculator site.

## Launch routes

- Time/work-hours experience on the homepage
- Hours Calculator
- Time Card Calculator
- Work Hours Calculator
- Time Clock Calculator
- Clock Out Time Calculator
- Hours & Minutes Calculator
- Decimal Time Calculator
- Time Card Calculator With Lunch
- Biweekly Time Card Calculator

## Local development

```bash
npm install
npm run typecheck
npm run build
npm run dev
```

All calculations are client-side. No database or account is required.
